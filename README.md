# Comptes X - droite et extrême droite françaises

`comptes.txt` : un handle par ligne, trié.

Périmètre : comptes publics de partis, élus (députés, sénateurs, eurodéputés, maires), cadres, organisations, médias et éditorialistes. Aucun particulier.

Sources des handles :
- Wikidata, propriété « nom d'utilisateur X » des membres déclarés des partis concernés (RN, LR, UDR, Reconquête, DLF, Les Patriotes, Identité-Libertés, Parti de la France, UPR, Ligue du Sud, SIEL, MPF, Les Identitaires, Action française, UNI) ; les personnes passées à un parti centriste ou de gauche sont exclues
- fiches officielles assemblee-nationale.fr (17e législature) et nosdeputes.fr (16e)
- fiches senat.fr et europarl.europa.eu
- sites des médias et pages X pour les journalistes et éditorialistes

Les comptes n'ont pas été ouverts un par un sur X : certains peuvent être renommés ou suspendus, et les données Wikidata peuvent être périmées. Toute correction est bienvenue via une pull request.
