# Comptes X - droite et extrême droite françaises

`comptes.txt` : un handle par ligne, trié.

Périmètre : comptes publics de partis, élus, organisations, médias et éditorialistes. Aucun particulier.

Les handles n'ont pas été vérifiés individuellement sur X : certains peuvent être erronés, renommés ou suspendus. Toute correction est bienvenue via une pull request.
